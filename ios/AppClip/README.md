# App Clip target files

These files are templates to add to a new App Clip target in Xcode.

1. Create App Clip target (`com.company.app.Clip`).
2. Add these files to that target membership only.
3. Set App Clip entitlements to `ios/AppClip/AppClip.entitlements` (or copy values into target capabilities).
4. Replace placeholders:
   - `fullAppAppStoreId` in `ClipInvocationModel.swift`
   - domain/API/app group values if different.
